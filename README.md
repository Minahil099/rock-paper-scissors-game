# 🪨📄✂️ Rock Paper Scissors Game

An interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

🚀 About This Project

This project is a browser-based Rock Paper Scissors game created to practice JavaScript logic, user interaction, and DOM manipulation.

🎯 Features
Rock, Paper, and Scissors choices
Computer-generated moves
Winner detection
Score tracking
Interactive gameplay
Reset game functionality
💡 Concepts Practiced
JavaScript Variables & Functions
Conditional Statements
Random Number Generation
Event Handling
DOM Manipulation
Game Logic
HTML & CSS Styling
🛠️ Technologies

HTML5 • CSS3 • JavaScript

🎓 Purpose

This project was created as part of my frontend web development learning journey to strengthen JavaScript fundamentals and build interactive browser-based applications.

⭐ A practice project built to improve my frontend development skills.
